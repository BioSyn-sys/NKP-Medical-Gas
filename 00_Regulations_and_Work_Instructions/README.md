# ระบบที่ 0: ระเบียบปฏิบัติและมาตรฐานการทำงาน (Regulations & Work Instructions)

โฟลเดอร์นี้รวบรวมระเบียบปฏิบัติงาน (SOP) วิธีปฏิบัติงานด้านสิ่งแวดล้อมและความปลอดภัย (Work Instructions) และเอกสารข้อกำหนดขอบเขตงานกลาง (TOR) สำหรับระบบก๊าซทางการแพทย์ของโรงพยาบาลนครพิงค์ เพื่อความปลอดภัยและเป็นแนวทางมาตรฐานเดียวกันสำหรับเจ้าหน้าที่
